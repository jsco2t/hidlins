## Implementation and review

- Added a single-owner `AuthoritativeVault` adapter. Network workers carry only authenticated identity and encrypted KDBX records and reach the unlocked vault through a fixed 16-slot synchronous host queue.
- Added mode-0600 sibling upload staging with contiguous 60 KiB chunks, a 256 MiB total cap, exact length/count/SHA-256 validation, automatic cleanup, and redacted diagnostics.
- Commit performs serialized compare-and-swap against actual encrypted bytes, authenticates the staged KDBX with the host password/keyfile, verifies root UUID and KDF equality, writes `.kdbx.bak`, atomically saves, and hashes the actual re-encrypted canonical result.
- Added `Vault::replace_database_and_save`; on a save error it reopens the complete canonical disk image so an after-rename durability error cannot leave live and disk state divergent.
- Added a reusable local-only TCP controller with accepted-peer address revalidation, exact V1 prefaces/framing, five-second Noise deadlines, IK static-key authorization before all application responses, eight fixed connection slots, 15-second I/O/host waits, five-minute session caps, bounded pairing admission, and logical advertisement lifecycle.
- Revocation replaces the active authorization set atomically. Unknown, provisional, and revoked keys complete no application exchange and receive no existence, version, or size metadata.
- Stop/lock/signal callers share `ServerController::stop`; it withdraws advertisements, closes every tracked accepted socket, wakes and joins the listener, and allows session and identity material to drop. Dropped host tickets automatically cancel work that has not reached the host commit point.
- Review repaired macOS accepted sockets inheriting the nonblocking listener flag, bounded the shutdown socket registry instead of retaining historical connections, tied pairing admission to the same monotonic three-minute deadline as advertisement state, and kept generic error mapping string-free.
- Added the discoverable `test-local-sync-integration` Make target. No external dependency was added in this task; `tempfile`, already locked and vendored, was promoted from dev-only use for secure sibling staging.
- `git diff --check` passed and the frozen approved-plan hash remained unchanged.
