## Implementation and review

- Added exact `_hidlins-sync._tcp.local.` and pairing-only `_hidlins-pair._tcp.local.` contracts with only `v=1` TXT data. Each server start uses 128 CSPRNG bits encoded as 26 lowercase Crockford characters for both the instance and non-device hostname.
- Added a bounded untrusted record DTO, atomic expiring candidate cache, exact instance removal, normalized endpoint deduplication, per-record/event/cache caps, conservative desktop expiry, and untrusted TTL clamping. No discovery type contains a peer key or authorization bit.
- Added a narrow permission-aware `DiscoveryPort`/`DiscoveryBatch` boundary suitable for native mobile callbacks and a deterministic simulated implementation. Permission denial and unavailable states are actionable and cannot mutate candidates.
- Added the restricted manual fallback as a direct call through `LocalEndpoint` parsing; DNS names and public ranges have no fallback.
- Added a macOS/Linux `mdns-sd` browser and advertiser. Browsing both service types converts results back through the core untrusted path. Advertising uses automatic interface refresh but a core-policy predicate prevents global/disallowed addresses from being published.
- Desktop stop, drop, and lock withdraw every registered advertisement and stop the daemon; pairing close/deadline withdraws only the pairing record.
- Review repaired an IPv6 backend mismatch: the backend's interface ID is retained only for link-local addresses and cleared for ULA/loopback before central validation. It also closed deterministic-label construction outside tests, made pairing-deadline overflow fail closed, and made malformed spoof events non-blocking for legitimate results while preserving atomic capacity failures.
- Added discoverable `test-local-sync-discovery` and expanded `check-feature-gates` with desktop compilation plus Android/iOS graph-absence assertions.
