## Implementation and review

- Added `LocalEndpoint`, the sole checked sync-endpoint type. It normalizes IPv4-mapped IPv6 before classification; allows only the frozen RFC1918, link-local, loopback, and IPv6 ULA ranges; requires a nonzero numeric scope for IPv6 link-local; rejects scope elsewhere; rejects port zero; and parses IP literals without DNS, URLs, interface names, or fallback.
- Added a separate construction-only `DiscoveryDestination` for exact IPv4/IPv6 mDNS multicast destinations. It cannot convert into `LocalEndpoint`.
- Added the exact twelve-byte V1 preface codec and allocation-free decoder for one big-endian, nonzero, at-most-65,535-byte Noise ciphertext frame.
- Added a hand-written binary application codec for the complete frozen V1 message table. It checks header and payload claims before copying, enforces exact booleans/types/widths/roles, rejects trailing and truncated bytes, caps chunks and transfers, and exposes a fixed 32-byte `RemoteVersion`.
- Added an atomic protocol state validator for trusted HEAD/fetch/upload/cancel/error flows and the pairing commit/prepared/activate/activated flow. Failed transitions operate on a clone and do not mutate sequence, request, or operation state.
- Review found and repaired three security issues before acceptance: unbounded completed-request tracking was replaced by constant-space monotonically increasing request IDs; outstanding HEAD requests are capped; and message/version debug output was redacted so encrypted bytes and protocol digests cannot enter diagnostics. The normative V1 document now records the monotonic-ID rule. Cancellation is accepted only during active chunk streaming.
- Added one centralized `ResourceLimit` table for numeric fixed limits, with below/equal/above tests for every variant and exact duration assertions. Codec/state paths consume the same constants.
- IPv4 tests cover every first/second-octet combination plus exact prefix edges and named special ranges (including CGNAT). IPv6 tests cover every possible first 16-bit segment, ULA/link-local edges, loopback, scope, multicast, documentation, mapped, unspecified, and global representatives.
- All production code is safe Rust and uses only the standard library plus already-present `thiserror`; no serializer, DNS/URL resolver, network crate, or dependency was added.
- `git diff --check` and crate-wide Clippy with warnings denied passed.
