## Main-thread review

Every iOS timeout captures an immutable generation, every browser callback validates both the active browser and generation, and every resolved service is associated with the generation that discovered it. Stop invalidates the generation before releasing browser/service ownership. Finish atomically claims the active generation before canceling its task and invoking the completion, which makes reentrant or delayed callbacks no-ops.

The test seam initially still called live Bonjour through the concrete browser. That allowed an unrelated OS callback to alter a test assertion, so browser search/stop operations were injected and made no-ops in lifecycle tests. The final iOS cases therefore retain real `NetServiceBrowser` delegate identities while controlling all activity synchronously.

Android had the same reachable defect: a queued old `Handler` timeout, discovery failure, or resolve callback could operate on a new `pending` result after stop/restart. The repair captures the attempt token in each asynchronous callback, checks both token and listener identity before mutation, and claims the token before completion/cleanup. No new dependency was introduced.
