## Main-thread review

The shared collector waits for a bounded 100 ms quiet period after the candidate set changes and resets that settlement timer when another batch changes the set. This avoids both the previous first-result exit and always waiting the full 500–2,000 ms discovery budget. The hard deadline, service kind, cancellation callback, address policy, deterministic ordering, and eight-connection attempt cap remain explicit.

The real desktop mDNS smoke test initially failed inside the filesystem/network sandbox with `Backend`; the deterministic suite passed. The exact task command passed outside the restricted local-network sandbox, confirming this was environment access rather than a product failure.
