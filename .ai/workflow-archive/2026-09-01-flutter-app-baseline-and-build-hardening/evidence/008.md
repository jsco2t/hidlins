## Main-thread review

Review preserved the approved ownership boundary: Rust alone owns secrets, lock policy, transfer lifetime, and session state; Dart carries typed non-secret results; Swift/Kotlin later own only OS mechanisms. No dependency was added.

Four high-confidence findings were repaired before acceptance:

1. The unused clipboard event API was a silent no-op on every platform. It and its unused repository/provider/model surface were removed.
2. A lock could interleave between secret resolution and ticket insertion. Mobile staging now revalidates the vault and inserts while holding the session guard, so either the lock wins and the secret is zeroized or insertion wins and the subsequent lock purges it.
3. A failed native dispatch could leave an unconsumed ticket until lock. Expired transfers are now zeroized by the existing one-second Rust ticker as well as on insert, consume, lock, and shutdown.
4. Desktop copy returned success when no clipboard port existed. A red/green regression now pins an explicit failure.

The staged Android artifact manifest records the exact FRB API manifest SHA-256 in addition to source/profile/ABI/file hashes. Its self-test rejects wrong API identity alongside stale source, wrong profile, wrong ABI, and wrong bytes.
