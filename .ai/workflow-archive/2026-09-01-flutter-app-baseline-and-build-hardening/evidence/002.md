## Main-thread review

The fail-before test first proved that the existing root was still the frozen
framework `MaterialApp`. A minimal real Hidlins shell then compiled and ran with
standalone Material, Riverpod, go_router, standalone localizations, and the
official temporary bridge. Review found that go_router detects only the legacy
`MaterialApp` and would otherwise fall back to no-transition pages. Explicit
standalone pages preserve navigation, restoration IDs, arguments, and error-page
behavior without leaking a dual type system. Once all first-party widgets were
migrated, the bridge was unnecessary and removed. No theme redesign, navigation
package replacement, or Cupertino import was introduced.
